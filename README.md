How to run everyfile!
IMPORTANT! MAKE A GITHUB ACCOUNT FOR METHOD 1
Method 1
1. Click <img width="100.8" height="40.2" alt="image" src="https://github.com/user-attachments/assets/9cad0f83-1eb3-47d6-bee4-6213bd309463" />
2. Click the highlighted button in the image <img width="280" height="380" alt="image" src="https://github.com/user-attachments/assets/e0664c0a-09e9-4ea1-a425-af3b5e12dd37" />
3. Click the blue <img width="400" height="200" alt="image" src="https://github.com/user-attachments/assets/fe2a761d-a1a5-4852-a1c4-043b2c85e615" />
4. Paste
```bash
file="NAME_OF_THE_FILE_YOU_WANT_TO_RUN"; if ! command -v dotnet >/dev/null 2>&1; then curl -fsSL https://dot.net/v1/dotnet-install.sh | bash -s -- --channel 10.0 || exit 1; export PATH="$HOME/.dotnet:$PATH"; fi; dotnet run "$file"
```
in the terminal and press Enter
